Troubleshooting

DANGER
Smoke, burning smell or sparks: press E-STOP, then switch the supply output off.
No output current, supply draw near zero
E-STOP is pressed. Twist it clockwise to release. Check supply On/Off is lit and generator Out1 is on.
Supply in CC, voltage dropping
5 A limit reached. Output off, check the wire loop for a short. If the loop is fine, report to the setup owner.
Supply shows OVP or a protection message
Press Esc or Enter to clear, confirm V-set = 40 V, then On/Off.
Thick or fuzzy scope trace
Check the probe uses the short ground spring. If it persists with the signal off, stop and report.
Current is half or double the expected value
Generator load setting: Utility → Output Setup → CH1Load must be High Z.
Amplitude jumps without input change
Reduce amplitude, output off, report.
DC shift in the sensor reading
Repeat the offset null step.
Lower current at high frequency
Expected. Loop inductance reduces current; shorten the loop or lower the frequency.
One area much hotter than the rest
Reduce amplitude, stop, report.
